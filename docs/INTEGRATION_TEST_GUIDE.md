# AI 채팅 투표 시스템 통합 테스트 가이드

## 테스트 목적
새로운 `user_votes` Map 구조가 전체 시스템에서 올바르게 작동하는지 확인

## 테스트 시나리오

### 시나리오 1: 새 투표 생성 및 참여
1. **사용자 A**가 새 투표 생성
2. **사용자 B**가 투표 알림 받음
3. **사용자 B**가 AI 채팅에서 투표 참여
4. 투표 상태가 "완료"로 변경되는지 확인

**확인 사항**:
- [ ] AI 채팅에 투표 카드가 표시됨
- [ ] 투표 전: "피클요청" 상태
- [ ] 투표 후: "완료" 상태
- [ ] Firestore에 `user_votes` Map 저장 확인

### 시나리오 2: 기존 데이터 호환성
1. 마이그레이션 전 생성된 투표 메시지 확인
2. 정상적으로 표시되는지 확인
3. 투표 상태가 올바른지 확인

**확인 사항**:
- [ ] 기존 투표 메시지 정상 표시
- [ ] 투표 참여 여부 정확히 표시
- [ ] 에러 없이 작동

### 시나리오 3: 동시 투표
1. **사용자 A**가 투표 생성
2. **사용자 B, C, D**가 동시에 투표
3. 모든 투표가 정상 집계되는지 확인

**확인 사항**:
- [ ] 모든 사용자의 투표가 `user_votes`에 기록
- [ ] 투표 수 정확히 집계
- [ ] 각 사용자의 상태 정확히 표시

### 시나리오 4: 타임아웃 처리
1. 10분 타이머 만료 대기
2. 투표하지 않은 사용자의 상태 확인

**확인 사항**:
- [ ] 투표한 사용자: "완료"
- [ ] 투표 안 한 사용자: "미참여"
- [ ] 타이머 자동 종료

## 문제 발생 시 확인사항

1. **"미참여" 상태가 계속 표시될 때**
   - Firestore에서 해당 메시지의 `user_votes` 필드 확인
   - 사용자 ID가 올바르게 저장되었는지 확인
   - `VoteStatusService.getUserVoteStatus` 로직 확인

2. **투표가 저장되지 않을 때**
   - Firebase Functions 로그 확인
   - 네트워크 연결 상태 확인
   - Firestore 권한 규칙 확인

3. **타이머가 작동하지 않을 때**
   - `vote_end_time` 필드 존재 여부 확인
   - 타임존 설정 확인
