1. PRESENTATION → DATA LAYER BYPASSING (Category: Layer Breach)
   Severity: CRITICAL
   Impact: Breaks Dependency Inversion Principle

   Affected Files:
   a) lib/features/auth/presentation/screens/login/login_page/login_page_widget.dart
      Lines: 3-6
      Violations:
      - Direct import of AuthRepositoryImpl (concrete implementation)
      - Direct import of FirebaseAuthRemoteDataSource
      - Direct import of AuthLocalDataSource
      - Direct Firebase package imports

      Business Impact:
      - Impossible to unit test without Firebase
      - Cannot swap authentication providers
      - Tight coupling to Firebase infrastructure
      - Violation of "Program to interfaces, not implementations"

   b) lib/features/auth/presentation/screens/signup/create_account/create_account_widget.dart
      Lines: 2-5
      Same pattern as login page widget

   Fix Strategy:
   - Implement Dependency Injection container in app layer
   - Create AuthServiceProvider in domain layer
   - Inject IAuthRepository through constructor or provider
