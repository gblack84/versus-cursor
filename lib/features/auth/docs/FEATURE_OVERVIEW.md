# Auth Feature - 기능 개요서

## 📱 개요
Versus Space 앱의 인증(Authentication) 기능은 사용자의 신원을 확인하고 안전한 접근 권한을 관리하는 핵심 모듈입니다. Clean Architecture v4.0과 Contract Pattern을 적용하여 확장 가능하고 유지보수가 용이한 구조로 설계되었습니다.

## 🎯 주요 기능

### 1. 다중 인증 방식 지원
- **이메일/비밀번호 인증**: 전통적인 이메일 기반 회원가입 및 로그인
- **소셜 로그인**: Google, Apple 계정을 통한 간편 로그인
- **전화번호 인증**: SMS OTP를 통한 안전한 전화번호 인증
- **익명 로그인**: 계정 없이 앱 사용 가능 (제한된 기능)

### 2. 계정 관리 기능
- **비밀번호 재설정**: 이메일을 통한 비밀번호 초기화
- **이메일 인증**: 가입 후 이메일 주소 확인 절차
- **계정 삭제**: 사용자 데이터 완전 삭제 (GDPR 준수)
- **프로필 업데이트**: 사용자 정보 수정

### 3. 보안 기능
- **SMS OTP 재전송 제한**: 3회 제한으로 남용 방지
- **세션 관리**: 자동 로그인 및 세션 만료 처리
- **재인증 요구**: 민감한 작업 시 재인증
- **토큰 관리**: JWT 토큰 자동 갱신

## 🔐 보안 특징

### SMS 인증 보안
- **3회 재전송 제한**: 스팸 방지 및 비용 절감
- **시간 제한**: 2분 내 OTP 입력 필요
- **PhonemaximumWidget**: 제한 초과 시 경고 화면

### 이메일 인증 보안
- **타이머 기반 검증**: 이메일 인증 시간 제한
- **자동 재전송**: 인증 메일 재발송 기능
- **실시간 상태 확인**: 인증 완료 즉시 반영

## 📊 사용자 플로우

### 신규 가입 플로우
```
시작 페이지 → 회원가입 선택 → 인증 방식 선택 → 정보 입력 → 이메일/SMS 인증 → 완료
```

### 로그인 플로우
```
시작 페이지 → 로그인 선택 → 인증 방식 선택 → 자격증명 입력 → 홈 화면
```

### 비밀번호 재설정 플로우
```
로그인 페이지 → 비밀번호 찾기 → 이메일 입력 → 재설정 링크 전송 → 새 비밀번호 설정
```

## 🎨 UI 화면 구성

### 주요 화면
1. **StartPageWidget**: 시작 화면 (로그인/회원가입 선택)
2. **LoginPageWidget**: 로그인 화면
3. **CreateAccountWidget**: 이메일 회원가입 화면
4. **PhoneCreatAccountWidget**: 전화번호 회원가입 화면
5. **PhonelogeinpincodeWidget**: SMS OTP 입력 화면
6. **ForgotPasswordWidget**: 비밀번호 재설정 화면
7. **PopupTimerEmailWidget**: 이메일 인증 대기 화면

### 보조 컴포넌트
- **PhonemaximumWidget**: SMS 재전송 제한 경고
- **EmailLoginForm**: 이메일 로그인 폼
- **SignupForm**: 회원가입 폼
- **OTPInputField**: OTP 입력 필드
- **ResendOTPButton**: OTP 재전송 버튼

## 🔄 상태 관리

### AuthProvider (Singleton)
- **중앙 집중식 상태 관리**: 모든 인증 관련 상태 통합 관리
- **GetIt DI**: 의존성 주입을 통한 싱글톤 패턴
- **실시간 상태 업데이트**: ChangeNotifier 패턴 사용

### 상태 종류
- `isLoading`: 작업 진행 중 표시
- `currentUser`: 현재 로그인한 사용자
- `errorMessage`: 에러 메시지
- `isInitialized`: 초기화 완료 여부
- `isEmailVerified`: 이메일 인증 여부
